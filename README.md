# Формализация математики на Lean

Это репозиторий курса по формальной матиматике в системе Lean, читаемого в Школе Анализа Данных осенью 2026 года. Он будет пополняться материалами (лекциями, семинарами, домашними заданиями).

## Установка

1. Установите git.
2. Установите VS Code и Lean по [инструкции с официального сайта Lean](https://lean-lang.org/install/).
3.
  Склонируйте репозиторий:
  ```
  git clone https://gitlab.manytask.org/lean/students-2026-fall/student_name
  ```
  Зайдите в него:
  ```
  cd student_name
  ```
  Загрузите скопмилированные зависимости. Это может занять продолжительное время и ощутимое место на диске: около 6 ГБ.
  ```
  lake exe cache get
  ```
  Докомпилируйте проект. Должно занять несколько секунд.
  ```
  lake build
  ```
4. Проверьте, что все работает корректно, открыв в VS Code файл `Test.lean` в корне репозитория. Файл должен прогрузиться без ошибок (может занять пару минут если диск медленный), а строка с `#check` выдать сообщение `TopologicalSpace.{u} (X : Type u) : Type u`.
